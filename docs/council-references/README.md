# Consejo de La Nave

Seis avatares conceptuales: Michael Jordan, Simon Sinek, Sabri Suby, Neil Patel, Alex Hormozi y Satya Nadella. Todos reportan a Hittan, sin jerarquía interna. No representan afiliación, aprobación ni opiniones privadas de estas personas.

Las referencias fotográficas consultadas están en sources.json. Las imágenes conceptuales y la interpretación 3D son generadas, no escaneos exactos. Se conservan ropa civil, rasgos, gafas y cabello distintivos.

La subida de archivos de Magnific estaba en mantenimiento. Se prepararon conceptos con el generador integrado y luego referencias equivalentes dentro de Magnific para alimentar Meshy sin subir archivos. generation-manifest.json registra los trabajos.

Cada malla se solicitó con 12.000 caras y textura estándar, con articulación Meshy. Las animaciones de escucha y atención son procedurales; no se clonan voces.

Los perfiles permanecen pausados hasta configurar fuentes y autorizar su uso; crear la representación no equivale a entrenar un modelo. Conversaciones previas e identificadores se conservan.
